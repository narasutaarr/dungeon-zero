# Dungeon Zero

A simple turn-based RPG console game built with Java.

## Features
- Turn-based combat
- Character and enemy systems
- HP and damage mechanics
- Potion and healing system
- Dungeon progression and boss battles

## Concepts
This project was built to practice Java fundamentals, methods, loops, conditional statements, and Object-Oriented Programming (OOP).

## How to Run
1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Compile the Java source files.
4. Run the `Main` class.

## About
Dungeon Zero is my beginner Java project, created as a hands-on exercise in learning programming and OOP.
